# Contributing to MediCare Hospital System

Thank you for your interest in contributing! We welcome bug reports, feature suggestions, and code contributions.

## Guidelines

1. **Fork & Branch**: Create a feature branch from `main` before starting work.
2. **Code Standards**:
   - Follow clean Java 11 coding standards for the backend.
   - Follow TypeScript strict typing for the React frontend.
   - Run type checks (`npx tsc --noEmit`) and Maven compilation (`mvn clean compile`) before submitting a Pull Request.
3. **Commit Messages**: Use Conventional Commit messages (e.g. `feat: add prescription export`, `fix: cors header origin check`).
4. **Pull Requests**: Submit a descriptive Pull Request targeting the `main` branch.
